CleanShot X 简体中文语言包
============================================================

一句话：双击「安装.command」，CleanShot X 就变中文。想恢复英文就双击「卸载.command」。


【适用条件】
------------------------------------------------------------
· macOS 13 或更高
· 已通过官方渠道获得授权的 CleanShot X（本包按 5.0.1 制作）
· Apple 芯片 / Intel 芯片都可以

CleanShot X 装在哪儿都行，脚本会自己找。

本包不含 CleanShot X 本体，也不修改程序文件，只是新增中文语言资源。


【怎么装】
------------------------------------------------------------
1. 先把整个文件夹解压出来（不要直接在压缩包里双击）

2. 双击「安装.command」
   会弹一个终端窗口，跑完自动打开 CleanShot X。

3. 如果提示「无法打开，因为来自身份不明的开发者」：
   在「安装.command」上点右键 → 打开 → 再点「打开」。
   还不行的话，打开「终端」，把下面这行粘进去回车，再双击：
       xattr -dr com.apple.quarantine ~/Downloads/CleanShotX-汉化包

4. 装完可能要重新给一次「屏幕录制」权限：
   系统设置 → 隐私与安全性 → 屏幕录制 → 取消勾选 CleanShot X，再重新勾上，
   然后退出 CleanShot X 重新打开。
   （因为改动了应用内的文件，系统会认为它是"新"的应用，这是正常的。）


【怎么卸载】
------------------------------------------------------------
双击「卸载.command」，逐字节还原成英文原版，同样是重签 + 重给权限。


【汉化范围】
------------------------------------------------------------
已汉化：
  · 状态栏菜单、编辑菜单
  · 设置窗口的正文（设置项标题、说明文字、下拉项、开关标签）
  · 文件名格式窗口、更新日志窗口、续订授权窗口

这个版本覆盖不到（仍是英文）：
  · 设置窗口左侧的栏目标签（General / Shortcuts / 快速访问 …）
  · 首次启动的引导画面
  · 截图 / 录屏的权限提示弹窗
  · 带链接的说明文字（如"前往壁纸设置"）

  这几处是硬编码在程序里的，要改必须往应用里注入代码。
  本包只做「语言文件替换」，不动程序本身，所以够不着它们。
  换来的是：包干净、不碰任何破解，可以放心公开分享。

刻意保留英文：
  · 品牌名 CleanShot X
  · 版本号（如 5.0.1 (02e6637)）
  · 快捷键符号（⇧⌘A 这类）
  · 通用技术缩写（API / GIF / YouTube 等）


【更新了 CleanShot X 怎么办】
------------------------------------------------------------
升级会整个替换掉 app 包，汉化就没了 —— 重新双击一次「安装.command」即可。

安装脚本会先比对「原版菜单文件的指纹」：

  · 界面没变（小版本升级通常如此）→ 全部照常汉化，菜单栏也是中文
  · 界面变了 → 只跳过菜单栏那一块，界面文字照常汉化，并提示是哪几个文件变了
  · 无论哪种情况都不会把应用弄坏

想让新版本的菜单栏也变成中文，需要重新生成语言包（拿新版重新构建一次）。


【这个包里有什么】
------------------------------------------------------------
安装.command              装
卸载.command              卸
使用说明.txt              本文件
汉化说明.md               技术细节（原理、覆盖路径、已知限制）
翻译对照表.csv            全部词条英中对照
zh-Hans.lproj/            中文语言包
  Localizable.strings       词表
  *.nib                     本地化的菜单与窗口
bundle-overrides/         框架自带资源包的中文语言文件
nib-manifest.txt          原版菜单文件的指纹，用来判断界面有没有变
nib-version.txt           生成时的版本号（指纹缺失时的兜底判断）


【不放心的话】
------------------------------------------------------------
· 所有脚本都是纯文本，可以用「文本编辑」打开自己看一遍
· 卸载是逐字节还原，装错了也能干净退回
· 安装前建议把 /Applications/CleanShot X.app 整个复制一份留底
